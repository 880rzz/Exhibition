# VIPACH Exhibition — SPONTÁN 2026

Multilingual static exhibition microsite for **SPONTÁN**, the VIPACH — Vienna Photo Art & Creative Hub group exhibition in Vienna.

## Routes
- `/` — English
- `/de/` — German (Austria)
- `/hu/` — Hungarian

## Event
- 15–22 November 2026
- Opening: 15 November 2026, 17:00
- CITYgalleryVIENNA by publicartists, Mahlerstraße 11, 1010 Vienna

## Technical
Static HTML/CSS with minimal progressive-enhancement JavaScript. No third-party fonts, analytics or tracking scripts. Includes hreflang, canonical URLs, Event/Organization JSON-LD, sitemap, robots.txt and llms.txt.

The exhibition poster is hosted in the official VIPACH Wix Media Manager and delivered from the Wix CDN.
