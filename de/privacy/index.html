Was passiert beim Aufruf der Seiten?

Die Website wird über GitHub Pages bereitgestellt. Laut GitHub protokolliert der Dienst die IP-Adresse der Besucherinnen und Besucher zu Sicherheitszwecken.

Um Bilder aus der Wix-Mediathek anzuzeigen, verbindet sich Ihr Browser mit dem Bilderdienst von Wix. Dabei übermittelt er technische Verbindungsdaten, darunter Ihre IP-Adresse.

Die öffentlichen Ausstellungsseiten verwenden im eigenen Code keine Skripte zur Reichweitenmessung oder Werbeverfolgung. Bei einem externen Link wird eine Verbindung zum jeweiligen Dienst hergestellt. E-Mail-Links öffnen Ihr E-Mail-Programm.

Direkte Sprachlinks öffnen die gewählte Version. Auf der neutralen Startseite wird anhand der Spracheinstellungen Ihres Browsers eine verfügbare Version gewählt. Die Spracheinstellung wird von dieser Auswahlfunktion weder gespeichert noch als Liste an einen Server gesendet.

Fotografien, Quellen und Berichtigungen

Die Ausstellungsseiten dokumentieren die Veranstaltungen. Soweit bekannt, nennen wir die Urheberinnen und Urheber sowie die Quellen für Bilder und Texte. Redaktionelle Texte und Übersetzungen unterscheiden wir von den Originaltexten der Kunstschaffenden.

Die Bilder der beiden Ausstellungen von 2025 werden auf Grundlage der Bestätigung des Veranstalters in diesem Online-Archiv gezeigt. Die Anzeige erteilt keine Erlaubnis zur Weiterveröffentlichung oder anderweitigen Nutzung.

Wenn Sie einen unrichtigen Namen, eine Bildunterschrift, Übersetzung oder Quellenangabe entdecken oder uns wegen einer Angabe oder eines Bildes zu Ihrer Person kontaktieren möchten, schreiben Sie an office@vipach.at. Bitte nennen Sie die Seitenadresse und die betreffende Stelle. Senden Sie in Ihrer ersten Nachricht bitte keine Ausweisdokumente.
